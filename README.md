\# Multidisciplinary Laboratory Management System (MLMS)



A comprehensive, role-based web application designed to streamline laboratory scheduling, live attendance tracking via QR codes, resource monitoring, and compliance reporting across multi-faculty academic streams.



\## 🚀 Tech Stack

\* \*\*Backend:\*\* Jakarta EE, Java Servlets, JDBC

\* \*\*Frontend:\*\* JSP (JavaServer Pages), HTML5, CSS3, JavaScript, Chart.js

\* \*\*Database:\*\* MySQL

\* \*\*Server Container:\*\* Eclipse GlassFish



\## ✨ Core Modules \& Features

\* \*\*Role-Based Access Control (RBAC):\*\* Secure authorization architecture separating portals for \*\*Admins\*\*, \*\*Lecturers\*\*, \*\*Students\*\*, and \*\*Technicians\*\*.

\* \*\*Live QR Projection Station:\*\* Real-time check-in gateway allowing students to scan dynamic session tokens for instant attendance logging.

\* \*\*Dynamic Monitoring \& Analytics:\*\* Live visual dashboards tracking lab occupancy rates, equipment statuses, and weekly verification distributions.

\* \*\*Automated Compliance Reports:\*\* Advanced filtering engine generating downloadable utilization metrics and attendance summaries.
